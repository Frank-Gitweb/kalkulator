# Kalkulator

En enkel kalkulator laget med HTML, CSS og JavaScript – mitt første vibecoding-prosjekt.

## Filer

- `index.html` – strukturen: skjermen og knappene
- `style.css` – utseendet: farger, størrelser og layout
- `script.js` – logikken: hva som skjer når du trykker på knappene

## Slik bruker du den

Åpne `index.html` i nettleseren. Du kan bruke musen eller tastaturet
(tall, + − * /, Enter for =, Backspace for å slette, Esc for å tømme).

## Ideer til endringer

- Bytt farger i toppen av `style.css`
- Legg til en knapp for kvadratrot
- Vis en historikk over tidligere utregninger
- Lag et lyst tema
